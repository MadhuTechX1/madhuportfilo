💻 Local Development Setup

No build tools, Node.js, or complex installations are required!

Option 1: Direct Browser
Clone or download this repository.
Double-click index.html to open it in any web browser (Chrome, Edge, Safari, Firefox).
Option 2: Local HTTP Server (Recommended)

Using Python's built-in server:

bash
# Navigate to the project folder
cd madhu-portfolio
# Start the server (Python 3)
python -m http.server 8000

Open your browser at http://localhost:8000.

🚀 Publishing to GitHub & GitHub Pages

Follow these step-by-step instructions to publish your portfolio online:

Step 1: Create a New GitHub Repository
Log in to your GitHub account: https://github.com/MadhuTechX
Click New repository (or visit https://github.com/new).
Set the repository name to portfolio (or madhu-portfolio).
Keep it Public and leave "Add a README" unchecked (we already have a complete one).
Click Create repository.
Step 2: Initialize Git and Push Your Files

Open your terminal or PowerShell inside the madhu-portfolio directory:

bash
# 1. Initialize git
git init
# 2. Stage all files
git add .
# 3. Commit the changes
git commit -m "feat: initial commit - publish personal portfolio website"
# 4. Set main branch
git branch -M main
# 5. Link to your remote GitHub repository (replace with your repo URL)
git remote add origin https://github.com/MadhuTechX/portfolio.git
# 6. Push to GitHub
git push -u origin main
Step 3: Enable GitHub Pages
Method A: GitHub Actions (Automatic - Recommended)
In your GitHub repository, click on Settings > Pages (in the left sidebar).
Under Build and deployment > Source, select GitHub Actions.
Because this repo includes .github/workflows/deploy.yml, GitHub will automatically build and deploy the site on every push to main!
Method B: Deploy from Branch (Classic)
Go to Settings > Pages.
Under Source, choose Deploy from a branch.
Under Branch, select main and folder / (root).
Click Save.

Within 1–2 minutes, your website will be live at: 🔗 https://madhutechx.github.io/portfolio/
